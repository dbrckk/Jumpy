# Jumpy — Experiment Backlog

The game is designed to be tested, not guessed into virality. Each change must target a measurable hypothesis.

## P0 — Core feel
1. Jump impulse A/B: default vs 5% lower gravity.
2. Perfect zone width: 44% vs 34% of platform width.
3. Air pulse strength: current vs 12% weaker.
4. Death-to-retry: tap-anywhere vs explicit retry only.

Primary metrics: first-run duration, retry within 10s, runs/session, perfect rate.

## P1 — Viral hooks
1. Share prompt only on personal best vs every 5th run.
2. Daily challenge default tab vs endless default.
3. Share copy with raw score vs percentile/rank once leaderboard exists.
4. Ghost replay preview on death screen.

Primary metrics: share CTR, invite/deep-link opens, daily-mode adoption.

## P2 — Retention
1. Skin unlock at lifetime-score milestones vs coin purchase.
2. 3 mission card vs single focused mission.
3. Streak reward at day 2 vs day 3.
4. Weekly modifier: low gravity, moving perfect zone, coin storm, narrow platforms.

Primary metrics: D1/D7, sessions/day, daily return rate, mission completion.

## P3 — Monetization only after retention
1. Rewarded revive after score threshold.
2. Rewarded double-coins post-run.
3. Cosmetic supporter pack.

Guardrails: retry latency, session abandonment, retention, crash rate. Never optimize ad impressions at the expense of the core loop.
