# Third-Party Notices

This file tracks external code, libraries, tools, generated assets and media incorporated into Jumpy.

## Current incorporated third-party content

None recorded beyond Godot Engine itself and standard project tooling.

## Recording rule

Before any autonomous integration of third-party code or assets, add an entry containing:
- name and source;
- exact version, release or commit when applicable;
- license;
- copyright/attribution requirements;
- files/components incorporated;
- reason for selection;
- date reviewed.

Research references that are not copied, vendored or distributed with Jumpy do not need an entry.
